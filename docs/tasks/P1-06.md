# P1-06 · ToSpec / ToTDD

合同P1-06/验收T-UNIT，状态语义来自BACKEND_SYSTEM§5（合同未细化）：locked→ready（前段批准），ready→running（用户手动），running→review（系统提交可审阅产物），review→discuss（用户讨论），discuss→review（系统交回），review→approved（用户批准）。批准仅解锁后继，不自动执行。

统一服务端判断；HTTP只开放start/discuss/approve，actor从已验签身份确定，不接受请求自签system或任意状态。expectedState+expectedRevision同时校验，防止讨论再提交后的旧批准。工作流后续调用同一服务执行submit/resubmit，要求真实同档案artifact引用；本批不开放未经验证的internal入口。

测试先行：全部36种状态对及每项动作/actor；真实PG初始化/同链幂等、前置未批准拒绝、用户不能提交或伪造actor、系统不能批准、跨账户/档案产物拒绝、批准解锁但不启动下一段、并发不同幂等键最多一次转移、同键重放、账本与状态故障一起回滚。相关模块行覆盖≥85%，独立测试与评审通过后才P1-07。

未定义阶段名不猜：提供可信调用方配置的通用线性链初始化；不在创建研究档案时虚构阶段，也不提前接任何模型。迁移新增同档案前驱与审阅产物复合外键。初始化及转移均在同一事务追加gate事件。
