# D-4 普通测试证据输出

## ToSpec

- 普通 `pnpm test` 的动态报告默认只写每次新建的系统临时目录，不更新仓库归档；`REINLAB_EVIDENCE_TASK` 不能授权仓库输出。
- 仅明确设置 `REINLAB_EVIDENCE_OUT` 时写入指定目录。保留现有报告文件名，输出 helper 不硬编码历史任务的 evidence 路径。
- 原生 race 父子进程使用父进程新建的唯一临时报告目录；父进程只读该次子进程的报告，子进程失败时不读取历史归档。显式要求归档时，验证成功后复制本次报告。
- 不改桥接生产逻辑、插件、前端或已有归档证据。

## ToTDD

1. 在临时工作区运行已有 Docker 独立报告写入流程，指定临时 OUT；先证明旧实现忽略 OUT（有效行为红灯），不触碰仓库历史证据。
2. 统一 test-evidence helper；验证默认目录唯一且位于系统临时目录、旧 TASK 不改变目的地、显式 OUT 生效。
3. 将角色、Docker、local 独立报告及 ledger 导出接到 helper；普通模式保持归档不变。
4. race 子进程报告通过唯一临时目录传递，定向原生回归确认结果来自当前子进程。
5. 定向运行 helper、角色原生/race、Docker、ledger 回归；只在 D-4 新目录显式保留报告，不跑全量测试。
