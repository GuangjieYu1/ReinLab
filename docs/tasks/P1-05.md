# P1-05 · ToSpec / ToTDD

合同§4.1/§6/§8.2–3及验收CH-3/CR-4/SEC-6：只追加真实账本，按档案序列续读SSE，导出JSONL及费用汇总。未知费用保持null，会员额度与GPU秒分列。仅服务端可追加；不开放任意写事件API、不提前接翻译层。

先测：真实PG下同键重放/冲突、四路并发、事务回滚、提交乱序不漏事件、跨账户与同账户跨档案引用拒绝；SSE分批读取、断线重连、Last-Event-ID、非法游标、鉴权、断开释放连接；审计顺序与费用精确一致、未知不作零费用、凭据脱敏、禁止更新删除。

方案：每账户追加前取得事务级锁，序号分配在锁之后（账户锁也防止单事务跨档案多次追加产生锁顺序循环）；SSE短事务读取后释放连接，断开取消等候，不占长事务；after与Last-Event-ID取较大值以避免重放，seq全局有间隙但档案可见事件不丢不重。审计单个SQL快照导出事件和汇总，同一快照界限固定；金额以六位小数字符串聚合，不用浮点累计。

DoD：本项真实PG/HTTP测试、行覆盖≥85%，独立测试与评审通过；原前端mock回归和构建通过。所有报告在evidence/P1-05。
