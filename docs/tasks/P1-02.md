# P1-02 · ToSpec / ToTDD

依据实现合同 §5、§6、§9 与 PRD 附录 A。只实现共享 schema 与类型，不实现业务执行、SDK 或翻译层。

先以有效合同样本、畸形输入、未知字段、越界数值、角色/作用域攻击样本写测试并记录红灯。然后实现：Citation/Risk、账本、5种卡片、研究委托/产出、运行令牌、记忆/升级、精读层/题目、8种群研工具参数，以及本批底座 HTTP 入参。

约束：Zod 为唯一运行时依赖；纯数据、无服务端类型；权限取值不允许 project/always；danger 作为风险标签允许解析，但执行权限绝不授予 danger；服务端才有批准/签核权，客户端不能自填 verified。

DoD：schema 正负样本全绿；lint 与 mock 回归通过；证据、独立测试与评审通过后才进入 P1-03。
