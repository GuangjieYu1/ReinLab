# REINLAB · 莱茵生命研究终端

可互动设计原型，已加入演示登录、连续开场、档案空间与原创环境音乐。非官方同人概念设计，与《明日方舟》、莱茵生命原作或 DeepSeek 官方无隶属关系。

## 本地真实精读

运行 `pnpm local:up22 --real-models`（固定用项目工具链的 Node 22；`pnpm local:up` 在 Electron 运行时里会直接报错退出），自动启动 supabase、控制面和 live 前端；打开 <http://127.0.0.1:5183> 登录本地账户，进入研究台精读。宿主网关直接读取受保护的 `~/.config/reinlab/local.env`，无需 `source` 或导出 key。
澄清上限 ¥0.05，正式精读按确认预算，以峰值费率保守预留；用量未知保留未知。普通 `pnpm local:up22` 默认不开真实模型，测试与 CI 使用 fixture。
若提示有未结束运行而延后账户升级，先结束旧运行，再执行启动命令。
测试脚本仅使用本机私有的 `fixture-users.env` 合成账户，不复用走查账户的 `verification-users.env`。
本地普通用户名登录映射到原账户，邮箱登录仍可用。修改私有 `verification-users.env` 的 `A_EMAIL`（用户名）和 `A_PASSWORD` 后，运行 `pnpm exec tsx services/control/scripts/sync-local-account.ts` 再重启；首次绑定需用 `--account <原账户ID>`，后续沿用已保存的账户 ID。

## 完整开场与档案空间

打开后先播放约 3.8 秒的登录前过渡：莱茵标志居中描绘、符号与名称出现、标志移向左侧，再展开 **LOG IN** 表单。可跳过入场；减少动态效果时直接显示登录。手机端标志向上退场再显示表单。

任意输入或留空均可接入；密钥不读取、不保存、不发送。点击登录后开始约 25 秒的连续演出，并自动停在文档库，不会自行抽取或打开文档。右上角可以跳过演出。

1. 终端文字接入。
2. 莱茵标志路径绘制、符号展开与左移。
3. 身份文字、请求接收与处理序列。
4. 黑白授权圆环、反向内弧、卫星点与中心图形。
5. 欢迎字样、公司名横向遮罩、数据库字样与白场。
6. 四列、128 份 CSS 立体档案入场，波峰传播与回传。
7. 选中档案浅抬升，镜头停留在文档库。
8. 用户主动抽取后，才执行镜头推进、双向扫描、标签揭示与磨砂清晰过渡。

开场及波动采用上游公开、以原片 25 fps 帧号标记的时间函数，连续轨迹在每个显示帧插值更新，不再将页面锁在 25 fps；镜头轨迹转写为 CSS
`matrix3d` 与 `perspective`，不使用 WebGL。开场中的身份信息是本地演出文字，
不代表真实账号验证。默认启用柔和闪切。

默认隐藏进度条。右上角调试按钮或 Ctrl/Cmd+Shift+D 可展开实测 FPS、P95 帧间隔、暂停、播放速度、时间拖动和 7 个分镜。
切到其他标签页会暂停演出，避免返回时已经错过片段。

登录后默认播放原创环境音乐（轻缓和弦与玻璃音色，48 秒循环），不使用参考视频音频。登录前可取消音乐，右上角随时静音；调试面板支持音量。声音从登录点击解锁，离开沉浸终端或切到后台会淡出。

性能路径采用稳定 DOM、逐帧差量写入、独立合成层、屏幕裁剪及档案材质分级：阵列共用轻量纹理，只有当前档案渲染多层光学结构。60 FPS 是目标，实际数值取决于设备、窗口、节能设置和浏览器调度；面板显示真实测量值，不硬编码 60。

档案阵列支持平台/档案切换、选中波动、抽取、拖动检查、复位、归位。
学习档案进入课堂，科研档案进入独立的 AI 研究实验室，其余档案仍进入原有工作区。
方向键选择、Enter 抽取、Esc 返回。
工作台右上角的 **沉浸档案** 可返回该场景；终端设置可重播完整演出。

这是参考驱动的完整动作链，不是原片视频背景，也没有声称逐像素复刻。
CSS/SVG 的玻璃材质不等同于实时光学折射，字形也尚未做逐字像素校准。

## AI 研究实验室 · 与课堂并行

科研列的档案经由同一套沉浸式抽取与镜头推进，展开为独立的研究实验室，
**不是课堂内部的一个学习单元**。工作台的科研入口、首页卡片、检索及最近打开
也指向这间实验室；课堂入口与六科记录保持不变。

设计参考为用户指定视频的 **01:25–01:35**：左侧持续展示共享状态、
当前最优方案和实验日志；右侧呈现研究讨论与模型结构、优化策略、
训练调度等实验方向。可以查看假设、对照指标和证据，继续本地演示轮次、
标记保留或淘汰，并记录自己的问题与手记。放弃的方向仍保留记录，
不会被从研究史中抹除。

这是前端交互设计：实验、数字及研究员发言均为明确标记的固定演示样例，
不是 DeepSeek Harness、真实模型训练、论文检索或自动科学发现。
研究记录按档案独立存储，不覆盖课堂或旧科研对话。原有科研对话数据保留，
可通过实验室之外的 **原有对话档案** 入口访问。参考片段只是本地设计资料，
没有被嵌入网页或随构建发布。

## 六种原生课堂 · 当前入口

默认学习档案为「群论」。登录 → 文档库 → 抽取档案 → 开启课堂 → 主任接续 → 进入课堂。
学习平台中的六种档案分别进入群论、模拟物理、CSAPP、历史专题、吉他、摄影；每份档案只呈现对应课堂，切换课程需归还档案后重新选择。
原首页「继续上次探索」读取最近打开的课程。开场、登录、档案材质与环境音轨保持原有流程。

- 原生 React 组件，不嵌套 iframe，不执行设计稿里的脚本，不使用 WebGL。
- 宽屏为左讲义、右交互对象、侧边持久手记。主界面底部不再设置问答栏；提问保存在手记旁。
- **群论**：六页原创讲义，依次覆盖对称操作、复合记号、群的定义、C₄ 运算表、单位元唯一性和局部核验。四个顶点一起追踪；表格可点击；证明分步展开。
- **数学画布**：固定的对象生成 → 连接 → 说明预演，节点可拖动、键盘移动与撤回。尚未连接 AI 或 tldraw SDK。
- **物理**：理想弹簧振子，参数调整、有限时长动画与对照记录。数值来自解析模型，不是实测。
- **CSAPP**：固定 C 程序的单步轨迹、数组与变量；第二种模式将讲义与同一轨迹并排。
- **历史**：本地打包的 Natural Earth 地理数据，D3/SVG 旋转、定位、讨论路径、自由笔迹与撤回。城市是现代定位参照，红线不是已核实的入侵路线；材料比较使用明确标记的虚构示例。
- **吉他**：原创指板示意视频在上、可定位谱面在下；另有合成音听辨。视频和示范音播放时降低背景音乐，不启用麦克风。
- **摄影**：保留局部批注、亮度预览和网格；第二种模式为六张矢量示意的接触表，支持三张选片与排序，不冒充实拍作品。
- 每科独立保存讲义位置、对象、笔记、草稿与最多 60 条证据。手写笔记可撤回；快照恢复只恢复对象，不覆盖笔记或其他证据。可以导出 Markdown。
- 主任使用真实的本地访问间隔，不虚构既往成绩。所有自由提问仅保存原话，未接真实教授。
- 数据键为 `reinlab-learning-classrooms-v1`。不兼容数据在首次写入前另存 recovery 备份；写入失败时提示导出。
- 维护可调整字号及笔记宽度；窄屏自动重排；尊重减少动态效果设置。

实现与检查记录见 `NATIVE_CLASSROOM_REVIEW.md`。

## 第一轮设计目标

- 统一的暖灰白研究环境、炭黑导航、鼠尾草与杏金局部信号。
- 用可操作网站验证入口、对话工作现场与模板工坊，不只是静态效果图。
- 禁止 WebGL：没有 canvas、Three.js、OGL 或着色器依赖。
- 优先使用 React Bits 中适合的 DOM 动效；档案层次使用 CSS 透视与原创 SVG。

### 事件驱动科研闭环原型

默认科研场景现由 `researchWorkflow.ts` 的内存事件投影驱动，不再按十秒时间点切换任务状态。仍是明确标注的本地模拟，不连接 DeepSeek、检索、训练或外部设备。刷新即重置本轮模拟；原有持久手记不受影响。

流程：三方向分配 → E07 完成但本轮未支持 → E08 候选 → E09 待资源 → 核验 E08 → Forum 解释与质疑 → a2/a5/a3 进入讨论 → 人工确认或自动规则 R1 → 联合实验 E11 → 核验与报告草稿。

- 人工确认点禁止继续派发；确认后才生成 E11。自动模式记录 R1：保持预算与数据条件，不新增外部访问。
- 执行状态与研究判断独立；待资源不会被当成假设失败，未核验候选不会进入 Champion。
- Log 可打开不可变事件快照；Forum 引用具体任务；Agent、方向、任务、候选与报告均有可点击详情。
- 历史回放只投影已发生事件，不修改当前会话，也不允许从回放中派发任务。
- SVG 位置由参与关系驱动；写入模拟结果之后才播放 Log 流转。视觉过渡使用 Motion，无 WebGL。

## 两种入口动线演示

开发服务器运行后，打开 `/?preview=entry-compare&variant=files` 或
`/?preview=entry-compare&variant=workbenches`，可在同一页面切换两种入口：

- **A / Files 优先**：开场 → 莱茵生命总 Files → 选中档案对应的动态 LOGO → 模块 Files。
- **B / 工作台优先**：开场 → 选择工作台 → 标识落章 → 模块 Files。

B 版默认是「量子涨落」。设计切换条上是七种：第五轮的量子涨落、莫比乌斯环、分形与群、混沌吸引子、晶带轴，以及按同一风格重做的制图详图、光圈对焦；授权双螺旋、档案匣架和第二轮三种收在「此前方案 · 5」下拉。离心机、八面体分子、档案中枢已移除。第一轮（工作台巡览 `orbit`、`fan`、`carousel`、`ribbon`）已从入口移除，旧链接回落到默认设计；其源文件暂留在仓库中，不再被引用。

第二轮入口设计沿用 Files 的大尺度、浅色材质与边缘文字布局。URL 的 `design` 参数支持：

- `matrix`：浮雕矩阵，连续的标识浮雕板构成整个场景，当前工作台从阵列中抬起，镜头在材质场上缓慢滑移。
- `glass`：档案抽取，复用 Files 的真实档案架、选择波纹与抽取镜头，二维动态标识在抽出的档案正面绘制。
- `axis`：档案穿行，复用 Files 的真实档案架与镜头位移，前景标识保持二维 SVG 绘制动画。

三版可以暂停和播放巡览；手动选择后停止自动切换，支持左右方向键。选择模块与进入模块共用原有 Files 交接流程，不改变普通应用入口。

矩阵保持原样；后两版的空间运动由原生 `ArchiveField` 承担，标识使用原有动态 SVG，不使用实体三维标识或 WebGL。选择后标识播放完整绘制动画，也可以点击“重播标识”单独查看；自动巡览为每个工作台留出完整绘制时间。档案正面可传入标识内容，普通 Files 仍使用原有正面。

第二轮复用现有 `BootStage`、`ArchiveField` 与 SVG 标识；第六个工作台为规划探索。

### 授权双螺旋（`design=helix`）

工作台优先的开场只播到授权圆环：默认从「授权圆环」一节（14.48 s）开始，在 17.7 s、欢迎字样和 Files 波浪之前交给选择界面。新场景的第一帧按开场源码在该时刻的几何精确复刻圆环（外环、白环、内圆、两侧弧、六个卫星点、金色轨道点），因此切换处看不出接缝。

- 交接：圆环向后倒下，展开成水平的扫描环；中心核心点拉成竖直轴线；六个卫星点向外散开，原位长成六块玻璃切片；背景从开场的灰色渐亮为纸白。
- 结构：六个部门是一条 DNA 双螺旋上的「碱基对」——玻璃切片位于两条串珠链之间，两端是金色节点与连杆。选中的切片停在扫描环中央并向前探出，玻璃上画出解密斜线和 AUTHORIZED 标签。
- 切换：滚轮、上下或左右拖动、点击其他切片、方向键都可以；螺旋像螺丝一样边转边升降，把新的部门送进扫描环，扫描环同时发出一圈脉冲。
- 进入：螺旋解开，串珠向外散开，连杆收回，其余切片飞离，选中的切片推向镜头；随后标识落章到 Files 中的档案匣上。

镜头、螺旋的转角、升降、开场缠绕与解开都是注册过的 CSS 属性，面向观看者的串珠与镜头运动始终同步。实现见 `CeremonyWorkbenchChooser.tsx` 的 `HelixScene`；开场截断见 `EntryComparison.tsx` 的 `RING_START` / `RING_HANDOFF`。其他设计在工作台优先下同样从圆环处切入；双螺旋和第五轮的五种做了无缝衔接。

### 第五轮：量子涨落 · 莫比乌斯环 · 分形与群 · 混沌吸引子 · 晶带轴

五种都像双螺旋一样从 17.7 s 的授权圆环直接接出（共用 `SeedRing`），都以选中的标识正对镜头结束，再交给落章。场景都在 `CeremonyWorkbenchChooser.tsx`，样式在 `ceremony-math.css`。滚轮、拖动、方向键、底部箭头都可以切换。

- **量子涨落（`design=quantum`，默认）**：圆环倒下成为“真空”地面——一片按零点涨落闪烁的点阵（2D canvas 铺在 3D 场景里），虚粒子对不断成对出现、分开、湮灭；地面上还有金色火花升起。六个部门是悬浮的未观测波包：概率云、虚化抖动的标识。一道“测量”光束落下，选中的波包坍缩成清晰的玻璃透镜，并在地面激起一圈涟漪。进入时其余波包退相干消散，被观测的态推向镜头。
- **莫比乌斯环（`design=mobius`）**：莱茵生命的 ∞ 做成实物——一条带半圈扭转的 8 字形缎带（莫比乌斯带），由约六十根细纤维织成。缎带用 2D canvas 自带透视投影绘制（不用 WebGL），按远近分段排序绘制，两个环在交叉处上下穿过；远处的部分像浅景深一样虚化，一道金色脉冲沿纤维流动。开场时 canvas 接过开场的白色圆环，把它捏成 8 字、展开成缎带再扭转。六个部门标在缎带上，切换时镜头沿缎带飞向该部门，右侧档案卡用引线连着缎带上的位置。进入时纤维解开四散，档案卡推向镜头。卡片和标签都是 DOM，每帧按同一投影定位。
- **分形与群（`design=fractal`）**：圆环倒下成为外接圆，母六边形、七个子六边形依次画出，再弹起 49 块板，每块上又刻着两级同样的图形（六角雪花分形）。六个外围子块是部门。切换是二面体群 D6 的群作用：相邻用旋转 rᵏ，正对面用镜面反射 s——整片分形沿镜面线压扁成一条线再镜像展开；右侧实时写出当前群元素。进入时镜头放大进选中的子块，它长成整体的大小（自相似），标识推向镜头。
- **混沌吸引子（`design=lorenz`）**：洛伦兹系统（σ 10、ρ 28、β 8/3）在载入时积分一次，整条轨道用 canvas 画成一根连续细线（与缎带同一套投影、排序和景深），开场时从原点向外画出蝴蝶两翼；金色示踪点沿真实轨道持续运行，两个不动点 C⁺、C⁻ 标在两翼中心。六个部门是相空间中的状态点，切换时镜头飞过去，右侧档案卡写出该状态的 (x, y, z)。进入时轨道碎成短段四散（初值敏感），档案卡推向镜头。
- **晶带轴（`design=crystal`）**：圆环留在原处作为测角仪，六个卫星点外移成六个晶带轴（[001]、[111]、[011]、[012]、[113]、[102]），每个对应一个部门。体心立方晶体从圆心凝聚出来并翻滚，看上去像杂乱的原子云，最后对准晶带轴——所有原子突然排成柱列。晶体后方出现该晶带轴真实的电子衍射斑点（满足晶带定律和体心立方消光规则），对准后前方浮出部门透镜。进入时晶格向外迸散，透镜推向镜头。

第五轮还有一层「编辑式阅读层」（受莱茵生命宣传片式的高对比排版启发，未照搬）：墨色实底的部门代码块（CURR / RSCH / ENGR / CRTV / AUTO / EXPL，切换时擦除并乱码解码）、场景背后的巨型淡色代码、右上角实时读数（取自场景本身：被观测的态、欧拉示性数 χ = 0、群元素、相空间坐标、晶带轴）、右下角部门索引、底部中英标语，以及一条始终跟随选中标识的引线标签。分形中选中的子块改为墨色。窄屏隐藏读数、索引、引线和标语。量子涨落的波包改为细密的干涉环纹，坍缩透镜外圈是墨色刻度环，后方的波包按深度虚化；分形母六边形加粗，远处的标识按深度虚化；晶带轴外加一圈墨色测角刻度，晶带轴标签改为部门代码。

### 第三轮入口设计（CSS 3D）

三种设计都是 CSS 3D 场景（不用 WebGL），材质沿用 Files 档案匣：磨砂玻璃、金色卡槽、螺丝与刻字。六个动态标识的 SVG 不做改动，只调整位置与时机。

三个场景共用一台镜头：俯仰、偏航与推拉是注册过的 CSS 属性，开场运镜、离场、鼠标视差，以及转身朝向观看者的物体，始终同步。

- `catalog`：档案匣架。托盘升起，六只立体档案匣由后往前落入槽位；当前档案匣被抽出并转向观看者，标识开始绘制。点标签或档案匣切换；进入时匣架下沉，选中的档案匣朝镜头推近。
- `drafting`：制图详图（已按第五轮风格重做，见下）。镜头从正上方倾下，平面图上的基准线、圆规圆与坐标依次画出，标识作为工位印在图上；当前工位折起一块玻璃立面，投影线连回平面上的圆。点工位重新投影；进入时镜头放平，正对立面，平面图收成一条线。
- `aperture`：光圈对焦（已按第五轮风格重做，见下）。有纵深的镜筒由远及近组装，对焦环旋转后对准当前工作台，六片叶片张开；六个工作台在倾斜轨道上环绕镜筒。选择时对焦环转动，光圈先收窄再张开；进入时镜头转到镜筒轴线上，镜筒从镜头旁掠过，只留下标识。

右下角可「重播开场」；任何选择都会结束开场。方向键切换，Enter 进入，键盘进入也播放离场动画。减少动态效果时直接显示最终状态。窄屏下画面上移，说明文字与编号排在底部；窗口较矮时隐藏左上品牌字。

### 制图详图、光圈对焦 · 第五轮风格重做

两者都加上了第五轮的编辑式阅读层（部门代码块、读数、索引、标语、引线），场景本身改为墨色与纸白的高对比：

- 制图详图：图纸加墨色粗外框，标题栏改为墨色实底；工位改为方形底座，下面是部门代码标签，选中工位反白为墨色；图纸前沿有一条导轨，墨色笔架沿导轨移到选中工位，金色光线指向它；立面改为墨色页眉的部门卡。读数是选中工位在图上的 X 坐标。
- 光圈对焦：镜筒改为石墨色，对焦环是黑色环面上的白色刻度与粗体数字，叶片改为深色，标识放在纸白圆盘上；环绕的部门改为墨色描边圆片加代码标签，选中的反白。读数是对焦环当前的角度。

- 工程开发（`EngineeringBench.tsx`）：一个档案是一个工作区（文件夹），里面的文件是一次次对话；工作区页有连接、环境、带计划进度的对话文件和共享的 Archify 结构。进入对话后采用 Agent Studio 的四栏编号布局（档案风格：墨色编号块、金色角线）：顶栏是 TODO 分段进度、模型、计划/执行、人工审批、存检查点、运行检查；01 前端预览按真实视口宽度渲染并缩放到面板内（适应 / 1280 / 768 / 390 预设与宽度标尺，标出 700px 容器查询断点），可叠加显示本次改动的区域、点选元素作为引用，⤢ 可放大到 01+02 的位置；切到资源是文件树、连接与同工作区对话；02 执行记录按计划步骤分组，左侧是事件脊线，底部是可点击的事件时间条；03 是按导入方向排布的模块依赖图（本次涉及的模块着色，Agent 正在处理的模块有流动虚线框）与模块详情，另有变更与检查点、终端、检查；04 开发助手顶部固定计划清单，开启人工审批时改动先在沙盒通过测试，再以审批卡片等你批准或驳回，批准后预览热更新。预览会按宽度真实重排：示例中的窄屏问题在 700px 以下让列表横排，批准修复后变为竖排。所有 Agent 行为均为本地示例，不连接模型、不改动真实文件。地址带 `conv=<序号>` 可直接打开某次对话。
- 创作（`CreativeBench.tsx`）：参照分镜工具的四栏：文案 → 分镜（结构、转场、时长可改，可排序/复制/删除）→ 画面编辑（镜头、版式，生成 4 个候选）/ 整片预览（真实按时长播放与转场）；底部时间线含画面、字幕、配音、音乐轨。按空行切分是真实的本地逻辑；「AI 语义切分」「生成候选」「导出 MP4」为预演，导出不生成文件。
- 自动化（`AutomationBench.tsx`）：左侧脚本与流程库（分组、类型筛选、最近 14 次运行的健康条），中间是流程节点图（触发/脚本/智能体/条件/审批/输出）和今日 24 小时调度总图，右侧检查器：脚本、配置与密钥（不显示明文）、运行日志、版本。「预演」沿主路径走一遍并追加一条预演记录；执行器未接入，「立即运行」与回滚不可用。
- 数据工程实验台（新增，`DataBench.tsx`，标识 `assets/workbench-logos/data.svg`）：参照微软开源的 Data Formulator：数据源与字段、可分支的数据线程、图形编码栏（图形、X、Y、聚合、颜色）、图表与结果表/原始表/SQL/Python、右侧 DataAgent。数据是页面内生成的示例数据（天气表明确标为非真实观测），图表、表格、相关系数与生成的代码都由当前编码实时算出；理解自由提问靠预设规则。它也已加入入口与 Files（见下）。
- 规划探索 · StarMap（`ExplorationBench.tsx`）：地点画成星点（拍摄点为取景准星并画出取景方向），路线是星座连线。左侧规划对话按预设调整会往地图上加点或改时间；底部全天时间轴可拖动或播放，地图上会显示此刻所在位置、已走路线、光线方向与金色/蓝调时刻，日落后地图转为夜间星图。地图为示意，光线按 10 月下旬估算。
