# 转场地图 · Motion Map

版本 0.1 · 2026-10-15 · 适用于正式入口 `?preview=entry` 及其后的工作台。视觉规范见 [RHINE_DESIGN_LANGUAGE.md](RHINE_DESIGN_LANGUAGE.md)。

## 三条原则

1. **每个转场都有一个「共享元素」**：前后两个画面里同一个东西，在切换时保持位置或形态连续，视线跟着它走，就感觉不到换了页面。
2. **每个前进都有对应的倒放**：返回不是另做一个动画，而是同一条时间轴反着播，用同一个共享元素。
3. **只动合成层**：转场里只改 `transform`、`opacity`、`clip-path`。不做大面积 `filter: blur`、不用 `backdrop-filter`、不逐帧改 `left/top/width/height`。

## 动效参数

| Token | 值 | 用途 |
|---|---|---|
| `--rh-ease-enter` | `cubic-bezier(.16,1,.3,1)` | 进入：快起慢落，落位感 |
| `--rh-ease-exit` | `cubic-bezier(.7,0,.84,0)` | 退出：慢起快走，不拖泥带水 |
| `--rh-ease-move` | `cubic-bezier(.65,0,.35,1)` | 移动 / 形变：两端都缓 |

| 时长 | 用途 |
|---|---|
| 160ms | 交叠淡入淡出（两层交接的那一下） |
| 420–480ms | 界面层退场、纸面覆盖 |
| 700–820ms | 面板/纸面展开收拢、场景入场 |
| 1.1–1.25s | 标识飞行、档案场显影 |
| 3.0s | 登录 → 选台（整段仪式） |

错开（stagger）：同一组元素依次 40–60ms；倒放时顺序反过来。

## 性能约定

- 正式入口与工作台之间用页内导航（`pushState`）切换，不整页刷新；标识转场层常驻在页面之外，跨页面连续。
- 重的部分提前在安静时刻构建：口令通过、核验的 1.4s 里先挂上档案场，交接时只放出选台。
- 交接时刻的大范围状态更新放进 `startTransition`，先让动画元素起飞。
- 选台期间预先把档案场提升为合成层（`will-change`），离场时不再整片栅格化。
- 莫比乌斯选台画布密度上限 1.5×，后层不加 `blur`。
- 测量方式：无头 Chromium 1440×900 @2×，逐帧记录 `requestAnimationFrame` 间隔与长任务；目标是每段转场无 >34ms 的帧。
