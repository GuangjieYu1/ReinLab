# 37 · 视觉拆解改后台：下完就回话，拆完再报 · 给 DSH 的开场

日期：2026-11-12。分支 `codex/creative-3`（基于 main `2280e75`）。

输入：[20-creative-contract.md](20-creative-contract.md) §14.7、§14.9；本文第三节是这批新增的约定，接受后我补进契约 §14.10。

## 为什么做

现在 `download_video` 是同步的：下载、切镜头、逐镜视觉拆解全跑完才返回。30 秒的片约 12 镜、一镜 20–55 秒，导演会话要等 **约 8 分钟**才回话，这期间作者什么都问不了。§14.9 已经让进度看得见了（视口进度条 + 对话里逐镜一行），但会话本身还是卡着。

## 要交的

1. **工具下完就返回**：`download_video` 下载 + 切镜头做完（约 10–20 秒）就回给模型：「下好了：文件名，共 N 镜，正在后台逐镜拆解，拆完会通知」。视觉拆解转到后台继续跑，不占着会话。
2. **后台拆解**：照现在的 `describeShots` 逐镜跑；每镜照旧推 `creative.focus`（带发起会话的 `runId`，`step: '视觉拆解 镜 N'`、`progress`、`detail`）。用量照旧按未知记账，挂发起会话的 `run_id`。
3. **拆完推事件**：推一条 `creative.ref`（形状见第三节），成功、失败都推。
4. **拆到一半时读得到**：`read_reference` 读一份还在拆的素材时，返回已拆好的镜头 + 一句「还在拆，k/N」，不报错、不等。
5. **会话结束不影响后台**：作者在拆解途中说别的、甚至新开会话，后台照跑。会话不再需要靠长工具续命。
6. **重启不丢**：后台任务的状态写进来源 `.json`（`breakdown: { state, done, total }`）。控制面启动时扫素材夹：`analyzing` 的从断点接着拆（已有的镜头描述不重拆、不重付费）。
7. **同时只拆一份**：后台拆解排队，一次跑一份（视觉模型一镜 20–55 秒，并发没意义还容易超时）；排队中的状态是 `queued`。
8. **去重照旧**：同一段已经拆完就直接复用；还在拆就回「这段正在拆，k/N」，不重新开一份。

## 三、事件 `creative.ref`（新增，契约 §14.10）

```ts
// 事件流 creative.ref：一份参考素材的拆解状态变了（开始、拆完、失败）
type RefEvent = {
  name: string;            // 素材文件名（不带扩展名），如「参考片段前30秒__bilibili-BV1BobV6kEpX」
  runId: string | null;    // 发起这次下载的会话
  state: 'queued' | 'analyzing' | 'ready' | 'failed';
  done: number; total: number;
  failure?: string | null; // 人话
  summary?: string | null; // ready 时：一两句总述（可以直接拼前几镜的景别+人物，不必再调模型）
};
```

逐镜进度继续走 `creative.focus`，`creative.ref` 只在状态变化时推。§14.3 那套完整的 `RefClip` / `/v1/creative/refs` 接口这批**不做**。

## 前端（Claude，你交了我接）

- 导演对话：收到 `creative.ref` `ready` 时在对话里加一行「拆好了：N 镜 · 总述」，失败就显示原因；作者接着说「按参考拆镜头」即可。
- 视口进度条已按 `creative.focus` 显示，不用改。

## 不做

- `RefClip` 全套接口、素材库搜索页、MediaPipe 逐帧数据（§14.2 其余几步）；
- 拆解结果不自动喂回导演、不自动接着出白模镜头——等作者开口。

## 规矩照旧

不加审计类测试；针对性回归两条：工具在拆解开始前就返回、重启后从断点接着拆不重复调用视觉模型。用量未知就记未知。`--no-gpg-sign`。

## 验收

1. 导演下载 BV1BobV6kEpX 前 30 秒：**20 秒左右回话**（文件名、共 N 镜、正在拆）；之后视口进度条和对话逐镜行照常走，约 8 分钟后对话出「拆好了」。
2. 拆到一半问导演「拆到哪了 / 先说说前几镜」：能答出已拆好的镜头。
3. 拆到一半重启控制面：起来后接着拆，已拆的镜不再调用视觉模型（用量表里看次数）。
4. 同一段再下一次：拆着时回「正在拆 k/N」，拆完后回「已经有了」。
