# 36 · 参考素材库：放链接 → 下载 → 拆解 · 给 DSH 的开场

日期：2026-11-10。分支 `codex/creative-3`（3B 之后，或和 3B 并行，DSH 定先后）。

输入：[20-creative-contract.md](20-creative-contract.md) **§14**。实验代码和结果：[creative-3/breakdown](../walkthroughs/creative-3/breakdown/)（`analyzer.html` 浏览器里逐帧 MediaPipe + 运镜块匹配，`events.py` 切事件，`vlm.mjs` 让 `doubao-seed-2-1-pro-260915` 写拆解表，`breakdown-seedance-img.md` 是产出样例）。

## 为什么做

用户：「放入视频链接……这样我们就有源源不断的素材积累了。」拆过的镜头进素材库，摆走位、写运镜、出片时引用；出片时还能拿参考镜头当第二段参考视频（「换人不换动作」）。

## 已经验证过的（照做）

- 表情：**先按身体关键点裁头部放大到 320 再跑 Face Landmarker**，否则中景都认不出脸；人脸 ≲ 40 像素就标「测不到」。
- 运镜：块匹配**每 6 帧比一次**，逐帧会把慢推吞掉（固定 0.992、推镜 1.116 是对的）。
- 视觉模型：账号能用的是 `doubao-seed-2-1-pro-260915`（`seed-1-6-vision`、`1-5-vision-pro` 都没开通）；一次 6 张关键帧 + 事件 JSON 约 1.4 万 token。
- 「走动」阈值实验里太敏感（误报全程走动），要按人物身高归一化、再看脚踝交替。

## 要交的

1. 下载：yt-dlp（必要时 lux / BBDown），≤720p、默认 ≤10 分钟、可取一段；cookie 文件只在进程内存里读；DRM 不下、不绕；失败说人话。
2. 拆解管线 §14.2 的 7 步；MediaPipe 在服务端怎么跑（Python 包 / 无头浏览器）你定，交付单写清楚。
3. §14.3 类型、§14.4 接口、`creative.ref` 事件；助手工具 `fetch_reference / search_references / read_reference`；镜头上可挂 `refShotId`。
4. 3B 出片支持「用这段参考的动作」：把参考镜头剪出来作为第二个 `reference_video`（同样走 TOS 预签名）。
5. 花费：视觉模型按 token 记（单价查清楚；查不到标未知）；下载、MediaPipe 不花钱。

## 不做

- 用 computer use 操作用户电脑；
- 下载有 DRM 的内容，或任何绕过版权保护的手段；
- 把参考原片放进作品或对外分享；
- 人偶按参考动作重定向（先存逐帧数据，下一批再做）；
- 前端（素材面板、拆解时间轴、镜头挂参考）我来做。

## 规矩照旧

契约已有语义不改，要改先回来说；不加审计类测试，针对性回归照写；费用只记不拦；key、cookie 只在进程内存里读；每批一个提交，`--no-gpg-sign`。
