# 32 · 创作台 MVP-2 · 人物形象（立绘和三视图）· 给 DSH 的开场

日期：2026-11-09。分支 `codex/creative-2`，从 main `778454b` 拉出（1D 已合并推送）。

输入：[20-creative-contract.md](20-creative-contract.md) **§12**（刚补）。类型、接口、事件、页面、验收都在那里。总体要求见 [19-creative.md](19-creative.md) §9。

## 为什么做

用户要尽快跑通全链路：小说 → 出图 → 白模 → 视频。小说这段已经通了，这一批做出图。MVP-3 的白模、镜头都要引用人物的稳定形象，所以这一批的重点是**资产 ID 稳定、版本清楚、文件存在自己这里**，图好不好看其次。

## 开工前要用户做的

- **火山方舟的 key**：`~/.config/reinlab/local.env` 里现在没有。请用户自己加一行（变量名 DSH 定，建议 `ARK_API_KEY`），我们不碰 key 的值。加好之前先把其余部分做完，出图那一步用真 key 验，不写模拟。

## 后端要交的

1. **设定字段**：`person.look`、世界观 `artStyle`，走现有的修订、版本、作品改写、提议；顾问的 `propose_setting` 能改 `look`。
2. **出图**：
   - 火山方舟 Seedream，模型选当前能用、支持参考图的那一版；平台做成可换的一层，换平台不改前端；
   - 先出立绘，三视图拿立绘当参考图出；只重出某几格时，拿 `from` 版的立绘当参考；
   - 描述由服务端按 `artStyle` + `look` + 作者的 `note` 拼，视图要求（正面全身、侧面、背面、白底）写死在服务端，不教模型别的；
   - 用 `creative_job` 或同类机制跑，每格的状态变化推 `creative.asset`。
3. **存文件**：
   - 平台返回的图当场取回存到 ReinLab 自己的存储（本机先用磁盘目录就行，路径 DSH 定），记宽高、大小；
   - 取回失败标 `unsaved`，留 `taskId`，`retry` 只取回不重付；
   - 文件接口带登录校验，`?download=1` 给原图下载。
4. **选用**：`PUT asset/selected`；快照里 `person.portrait` 填好选用版的立绘地址。
5. **花费**：每张图记一条 `usage_record`（`purpose: 'creative_image'`），按官方价格页的峰值价估；平台没给用量就记未知。只记不拦。

## 不做

- 顾问自己调出图（这一批顾问只能提议改外貌）；
- 场景、地点出图，白模、视频（MVP-3）；
- 画风参考图上传、按作品换画风；
- 前端页面：人物卡、四格、头像转圈我来做（契约 §12.5）。
