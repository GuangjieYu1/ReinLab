# 33 · 创作台 MVP-3 · 从小说场景到成片 · 给 DSH 的开场

日期：2026-11-10。分支 `codex/creative-3`，从 main `3260f6e` 拉出（MVP-2 已合并推送）。

输入：[20-creative-contract.md](20-creative-contract.md) **§13**（刚补）。类型、接口、事件、页面、验收都在那里。总体要求见 [19-creative.md](19-creative.md) §3、§9。

## 为什么做

全链路最后一段：小说 → 出图 → **白模 → 视频**。作者挑一场正文，分镜导演在看板上搭白模、摆人偶和机位、列镜头；作者看着改；每镜真出视频，选好拼成成片。

## 分两半交

**先交 3A（不花出片的钱），我接页面验收；再交 3B（真出片）。** 3A 交了就回我，不用等 3B。

### 3A 后端要交的

1. **设定字段**：`place.room`（轮廓、层高、原点、朝向）、`person.body`（身高、体型），走现有修订和提议。
2. **白模**：归地点、有版本；`whitebox.prim.*` 的 op；`GET places/:pid/whitebox`。
3. **镜头**：归作品的一场；`shot.*` 的 op；`GET works/:wid/scenes/:sid/shots`；白模、人物形象出新版或正文这段改了，镜头的 `stale` 写人话原因。
4. **预演片段**：`POST shots/:shotId/preview` 收前端录的片段和首帧，存成资产（和 MVP-2 的图同一套存储）。
5. **分镜导演模式** `creative_director`：
   - 和顾问、写作助手同一套（会话、续一句、`creative.focus`、提议、改一下、`supersedes`）；
   - 读工具：场景正文、相关设定、人物形象（三视图地址）、地点房间和白模、已有镜头；
   - 写：只能交 `whitebox`、`shots` 两种提议；**不能出片**；
   - 1D 的预览接口支持这两种提议（`ItemChange` 的 kind 加 `prim`、`shot`）；
   - 提示词只写底线：镜头 4–10 秒；人物站位要在房间轮廓里；机位不要穿墙；回复里不复述镜头明细。

### 3B 后端要交的

1. **出片**：火山方舟 Seedance，用账号能用的最新一档（2.5 或 2.0，你看哪个能开通、哪个便宜好用）；平台做成可换的一层。
   - 「全模态参考」：人物三视图当参考图（总共不超过 9 张），预演片段当参考视频，提示词服务端按镜头的动作、对白、光线、画风拼；
   - **先查清**：参考视频能不能用 base64 或文件上传传给平台，还是只认公网地址。只认公网地址就退到「预演首帧当参考图 + 提示词写运镜」，`basis.mode` 记 `reference_image_only`，交付单写清楚；
   - 异步任务轮询，每次状态变化推 `creative.take`；取回存本机，失败标 `unsaved` 可只取回。
2. **选用和拼片**：`PUT shots/:shotId/selected`；`POST scenes/:sid/cut` 用 ffmpeg 按顺序硬切拼接，推 `creative.cut`。
3. **花费**：每个候选一条 `usage_record`（`purpose: 'creative_video'`），按官方价算成已知（按秒或按 token，单价放 provider 层）；没出成的记 0 并注明平台未收费。只记不拦。
4. 下载文件名带作品、场、镜号、候选号。

## 不做

- 配音、配乐、字幕、转场；
- 导演自己出片；
- 后端三维渲染（预演由前端录）；
- 前端页面：视频面、视口、镜头条、出片格子我来做（契约 §13.6）。现有 `VideoFace.tsx` 是纯前端示例，我会换成真的。

## 预算（真实花钱前我会再报一次）
