# 地基第 5 项 · 登录会话 · 验收（`codex/session-5`）· 2026-10-30 22:30

录像 `video.mp4`，截图 `shots/`。前端由 Claude 按 `design/prd/04-session-contract.md` 改，服务端由 DSH 实现。

| 编号 | 做了什么 | 结果 |
|---|---|---|
| S1 | 登录后整页重新加载档案页，再重新加载入口页 | ✓ 直接回到 InstructGPT 档案；入口页直接进选台，不用重新输密码。`document.cookie` 为空（HttpOnly） |
| S2 | 停掉控制面后刷新，再重启整套服务 | ✓ 停掉时显示"连不上本地服务 · 登录没有丢"，没有跳到登录页；重启后点"重试"回到原档案 |
| S3 | 入口选台和嵌入的第二标签（打开着档案）同时在线，在选台点锁定 | ✓ 两处都回到登录页；库里有效会话为 0；刷新仍是登录页；重新登录后自动回到原来的档案 |
| S4 | 锁定前后比对该账户的待批请求和运行中/等待中的任务 | ✓ 4 条待批、4 个等待中的运行，锁定并重新登录后完全一致，没有被取消或自动批准 |
| S5 | 在库里改 `last_used_at` / `created_at` 后刷新 | ✓ 空闲 31 天：要求重新登录，提示"登录已过期"；改回现在：同一 Cookie 恢复可用；89 天时访问：空闲期限顺延、`created_at` 不变；91 天：过期 |
| 补充 | 页面开着 45 秒不操作 | ✓ `last_used_at` 不变，轮询不算使用 |

Claude 验收中补的前端：连不上服务时每 5 秒自动重试，断网时没完成的锁定也一起补上。

说明：S4 没有专门起一个正在调用模型的任务（会花钱），用的是库里等待批准的运行。锁定只撤销会话这一行，不碰运行表。
