# 研究台「精读」真实试用报告

2026-10-26 · 用真实的 DeepSeek 走了两遍 · 总共花了不到 1 毛钱（授权上限 ¥3）

## 一句话结论

**登录和进入研究台已经能用；但「跟助手说想读哪篇」这一步卡住了，后面的精读没走到。**

## 能用的

- 登录：密码输错会被拦下，并提示核对；留空会提醒先填；输对后正常进入。
- 选工作台、抽档案、进入研究台：动画完整，中途不会掉登录。
- 还没上线的「群研」「自研」显示为灰色，并标注哪一期上线，点了不会乱跳。
- 助手真的在用 DeepSeek 检索论文，会把候选论文列出来让你选，不会替你做决定。

## 不能用的，以及原因

| 你会看到 | 原因（大白话） |
|---|---|
| 助手列出的 3 篇里没有你要的 Toolformer | 它只搜一次，只看前 3 条，还不允许先想「你说的大概是哪篇」再按标题去搜。规则定得太死 |
| 点「都不是」后，助手请你补充，你补充了，它却回「澄清未受理」 | 你打的字没有被当成「回答助手的问题」，而是当成了一次新请求，系统把它拒绝了 |
| 之后哪怕新开一份精读，也一直显示「未受理」 | 上一次对话卡在半路没有结束，系统为了防止多花钱，把整个账户的新对话都停掉了，界面上也没有「结束它」的按钮 |
| 明明花了钱，底栏还显示「¥0.000」 | 金额取错了地方，取的是「还没结算」的数字 |
| 一进来收件箱就弹出一段看不懂的代码 | 本该只出现在对话里的提问被推到了收件箱，还把原始数据直接显示出来了 |
| 刷新页面就要重新登录 | 已知问题：登录状态只存在页面里 |

## 下一步

1. **后端（Codex）修四件事**：
   - 让「补充说明」接回同一段对话；
   - 卡住的对话可以结束，且不连累整个账户；
   - 让助手先猜标题、再多搜几次、每次多看几条；
   - 金额显示真实花费。
2. **前端（Claude）修四件事**：
   - 收件箱里的原始数据折叠起来；
   - 加一个「停止澄清」按钮；
   - 「换一篇」后可以直接重选；
   - 拒绝下载后，状态不再写「已完成」。
3. **修完用同一个脚本再录一遍**，这次要一直走到精读完成、拿到发现卡。
