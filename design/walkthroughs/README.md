# 全流程走查（Walkthrough）

用户 2026-10-26 定：**每完成一个工作台的大功能，做一次全流程走查；完成一整个工作台，再做一次整台走查。**

## 每次交付三样东西

| 交付物 | 给谁看 | 内容 |
|---|---|---|
| `video.mp4`（短片） | 用户 | 真实浏览器录屏。画面顶部有字幕条：当前步骤、预期、实际结果（✓ 符合 / ✗ 有差距 / △ 部分符合） |
| `RESULTS.md`（给 AI） | Codex / 以后的 Claude | 逐步记录：步骤 ID、操作、预期、实际、是否有差距、原因定位（文件 / 接口 / 事件序号）、归属（前端 Claude / 后端 Codex）、修复建议 |
| `REPORT.md`（给小白） | 用户 | 一页纸：能用了什么、哪里还不行、为什么、下一步，不出现代码 |

## 做法

1. **先写 `PLAN.md`**：全流程分步，既有正确路径，也有错误分支（输错、拒绝、超预算、取消、刷新等）。每一步先写清预期，再动手。
2. **在真实模式上跑**（`pnpm local:up --real-models`，入口 http://127.0.0.1:5183），用 Playwright 驱动并录屏。账户从本机文件读进脚本，不出现在对话、截图和日志里。
3. **真实花钱先拿用户授权**：PLAN 里写明总预算上限，用户同意后才跑；跑的过程中超出上限就停下。
4. 跑完逐步对照预期，写 RESULTS 和 REPORT。**差距照实写，不改预期去迁就实际。**

## 目录

`design/walkthroughs/<日期>-<工作台>-<功能>/`：PLAN.md、RESULTS.md、REPORT.md、video.mp4、shots/。
